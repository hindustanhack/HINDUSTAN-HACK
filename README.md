# 🛡️ Hindustan Hack

**Hindustan Hack** is a powerful, lightweight CLI suite designed for Termux and Linux, featuring advanced phone number intelligence and OSINT lookup capabilities[span_0](start_span)[span_0](end_span).

### ✨ Features
- 🔍 **Number Lookup (OSINT):** Query mobile numbers via secure API endpoints with detailed record extraction[span_1](start_span)[span_1](end_span).
- 📊 **Rich Data Tables:** Formats records, registration info, Aadhaar details, and telecom circles into clean, color-coded tables[span_2](start_span)[span_2](end_span).
- 📱 **Mobile Friendly:** Designed specifically for Termux and narrow terminal displays[span_3](start_span)[span_3](end_span).
- ⚡ **Batch Processing:** Support for querying multiple comma-separated numbers simultaneously[span_4](start_span)[span_4](end_span).
- 🎨 **Terminal UI:** Built using Python's `rich` library and `pyfiglet` for visual headers[span_5](start_span)[span_5](end_span).

### 🛠️ Prerequisites
Make sure you have Python 3 and Git installed on your system or Termux[span_6](start_span)[span_6](end_span).

### 📥 Installation & Deployment

Open Termux or your terminal and execute the following commands:

```bash
pkg update && pkg upgrade -y
pkg install python git -y
git clone https://github.com/hindustanhack/HINDUSTAN-HACK
cd HINDUSTAN-HACK
pip install -r requirements.txt
python3 hindusosint.py
```
